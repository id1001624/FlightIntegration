# 專案核心範圍與事實

## 1. 專案範圍 (Project Scope)

本專案的核心業務範圍已明確定義為 **國際航空路線**。

- **包含**: 所有國際航班，包括在台灣進行轉機的航班。
- **不包含**: 純粹的台灣國內航線（例如：台北到高雄）以及離島航線（例如：台北到金門）。

所有功能開發、數據篩選和測試都應基於此核心範圍。

## 2. 關鍵技術事實 (Key Technical Facts)

- **機場地區資料來源**: 機場的國家/地區資訊的唯一真實來源 (Source of Truth) 是後端資料庫 `airports` 資料表中的 `country` 欄位。
- **前端分類器**: 前端 `flightService.js` 中的 `_getAirportRegion` 函式是一個臨時性的前端分類器，現在應被視為**技術債**。未來的重構任務應包含將此邏輯遷移至後端，直接使用資料庫中的 `country` 欄位。
