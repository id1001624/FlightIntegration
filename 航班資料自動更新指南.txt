# 台灣航班整合系統 - 航班資料自動更新與清理指南

本指南說明台灣航班整合系統中航班資料的自動更新與清理機制，幫助您理解和管理系統的數據流。

## 資料生命週期概述

在本系統中，航班資料遵循以下生命週期：

1. **資料獲取**: 通過 TDX API 和 FlightStats API 獲取航班數據
2. **資料處理**: 標準化來自不同源的數據並生成票價資訊
3. **資料儲存**: 將處理後的數據保存到 PostgreSQL 資料庫
4. **資料查詢**: 通過系統 API 和前端界面查詢資料
5. **資料清理**: 定期移除舊數據，保持資料庫效能

## 自動化腳本說明

系統包含以下自動化腳本：

### 1. 數據更新腳本
- **腳本名稱**: `update_flights_only.bat`
- **功能**: 僅更新航班數據，不處理其他數據
- **建議執行頻率**: 每天多次（例如每6小時）
- **參數配置**: 可通過編輯腳本修改獲取數據的天數和範圍

### 2. 數據更新與超時監控腳本
- **腳本名稱**: `auto_update_tonight.bat`
- **功能**: 在特定時間執行完整數據更新，包含超時監控和錯誤處理
- **建議執行頻率**: 每天一次（通常安排在凌晨時段）
- **特點**: 包含自動重試和任務監控機制

### 3. 數據清理腳本
- **腳本名稱**: `auto_cleanup_data.bat`
- **功能**: 清理舊的航班和票價數據，優化資料庫
- **建議執行頻率**: 每天一次（建議在數據更新完成後執行）
- **參數設置**:
  - 保留天數: 90天（可配置）
  - 數據類型: 所有數據（可配置為僅清理測試數據）
  - 備份選項: 啟用（可禁用）

## 設置排程任務

為確保數據定期更新和清理，建議設置以下排程任務：

### 數據更新排程
1. **每6小時更新**:
   - 腳本: `update_flights_only.bat`
   - 建議時間: 6:00, 12:00, 18:00

2. **夜間完整更新**:
   - 腳本: `auto_update_tonight.bat`
   - 建議時間: 凌晨2:00

### 數據清理排程
1. **每日清理**:
   - 腳本: `auto_cleanup_data.bat`
   - 建議時間: 凌晨3:00（在完整更新後）

詳細的排程任務設置說明請參考 `README_排程任務設置.txt` 文件。

## 腳本執行原理

### 數據更新流程
1. 腳本啟動 → 連接 API 獲取數據 → 處理並標準化數據 → 更新資料庫 → 生成日誌

### 數據清理流程
1. 腳本啟動 → 識別舊數據 → 備份舊數據 → 刪除舊數據 → 生成清理報告

## 監控與維護

### 日誌文件
- 更新日誌: `logs/app.log`
- 清理日誌: `logs/cleanup_old_data.log`
- 錯誤日誌: `logs/cleanup_error.log`

### 備份文件
- 位置: `backups/` 目錄
- 命名: `flights_backup_[timestamp].json`
- 格式: JSON 格式，包含航班和票價數據

### 健康檢查
1. **定期檢查日誌**：查看是否有錯誤或警告信息
2. **監控備份大小**：確保備份空間充足
3. **檢查數據更新情況**：通過前端查詢最近一週航班確認數據是否正確更新

## 故障排除

1. **API 無法連接**：
   - 檢查網絡連接
   - 驗證 API 金鑰是否有效
   - 確認 API 配額是否超限

2. **數據更新失敗**：
   - 檢查 `logs/app.log` 中的錯誤信息
   - 確認資料庫連接正常
   - 手動執行更新腳本測試

3. **清理腳本異常**：
   - 檢查 `logs/cleanup_error.log`
   - 確認資料庫權限是否足夠
   - 檢查清理參數是否合理

## 重要注意事項

1. **不要在高峰使用時段執行清理操作**：避免影響用戶體驗
2. **定期檢查備份文件夾大小**：長期運行可能積累大量備份
3. **在大規模更新前建議手動備份**：例如更改保留天數前
4. **監控資料庫大小**：確保資料庫空間足夠
5. **定期測試排程任務**：確保自動化流程持續有效

## 自定義配置

各腳本均可通過編輯相應的批處理文件進行配置：

1. **修改航班數據獲取範圍**：
   - 編輯 `auto_update_tonight.bat` 中的日期參數

2. **修改資料保留天數**：
   - 編輯 `auto_cleanup_data.bat` 中的 `RETENTION_DAYS` 參數

3. **調整備份設置**：
   - 編輯 `auto_cleanup_data.bat` 中的 `BACKUP` 參數
