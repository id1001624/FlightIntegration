# 航班資料自動清理排程任務設置說明

本文件說明如何在 Windows 系統上設置排程任務，以自動定期執行航班資料清理操作，保持資料庫整潔高效。

## 清理腳本說明

`auto_cleanup_data.bat` 腳本會自動執行以下操作：

1. 刪除 90 天以前的所有航班資料（包括真實資料和測試資料）
2. 對應的票價資料也會一併刪除
3. 刪除前會自動備份被刪除的資料到 `backups` 資料夾
4. 操作日誌會記錄在 `logs` 資料夾中

## 設置自動排程任務步驟

### 1. 開啟工作排程器

- 按 `Win + R` 開啟執行對話框
- 輸入 `taskschd.msc` 並按確定
- 工作排程器視窗將會開啟

### 2. 創建新的排程任務

- 在右側操作面板中點選「建立基本工作...」
- 輸入任務名稱（建議：`航班資料自動清理`）和描述
- 點選「下一步」

### 3. 設定任務觸發條件

- 選擇「每天」，點選「下一步」
- 設定開始時間（建議選擇系統使用率較低的時間，如凌晨 3:00）
- 點選「下一步」

### 4. 設定動作

- 選擇「啟動程式」，點選「下一步」
- 在「程式或指令碼」欄位中，輸入批次檔的完整路徑：
  ```
  C:\完整路徑\auto_cleanup_data.bat
  ```
- 在「新增引數」欄位中，輸入 `silent`（這樣執行時不會暫停等待）
- 在「起始於」欄位中，輸入專案根目錄的完整路徑
- 點選「下一步」

### 5. 完成設定

- 勾選「當按一下『完成』時，開啟此工作屬性對話方塊」
- 點選「完成」

### 6. 進階設定（選填）

在開啟的屬性對話方塊中：

- 「一般」標籤：勾選「不管使用者是否登入都執行」選項
- 「設定」標籤：勾選「如果工作執行超過以下時間，則停止工作」，設為 1 小時
- 點選「確定」儲存設定

## 測試排程任務

建立任務後，可以在工作排程器中手動測試：

1. 找到剛建立的任務
2. 右鍵點選該任務
3. 選擇「執行」
4. 確認清理操作是否成功執行（查看 `logs` 資料夾中的記錄）

## 排程任務設置建議

- **執行頻率**：建議每天執行一次
- **執行時間**：建議在凌晨 3:00 等系統負載較低的時段執行
- **備份保留**：定期檢查 `backups` 資料夾，避免備份佔用過多硬碟空間

## 注意事項

1. 請確保執行排程任務的帳戶具有足夠的權限
2. 如需修改清理的天數設定，請編輯 `auto_cleanup_data.bat` 文件中的 `RETENTION_DAYS` 參數
3. 如果不需要備份功能，可修改 `auto_cleanup_data.bat` 文件，移除 `--backup` 參數
4. 若有大量資料，可能需要增加任務的最大執行時間

## 故障排除

若排程任務未正常執行，請檢查：

1. 排程任務的執行狀態和歷史記錄
2. `logs\cleanup_error.log` 中的錯誤訊息
3. 確認執行帳戶具有足夠權限
4. 確認 Python 環境變數設置正確

若問題依然存在，請聯繫系統管理員或查閱完整的錯誤日誌以進行進一步排除。
