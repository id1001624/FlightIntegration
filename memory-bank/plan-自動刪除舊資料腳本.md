# 自動刪除 flights、ticket_prices 資料庫舊資料的腳本計畫

## 需求分析
- **核心需求**:
  - [ ] 自動定期刪除 flights 表中的舊資料（超過一定時間的航班記錄）
  - [ ] 自動定期刪除 ticket_prices 表中的舊資料（超過一定時間的票價記錄）
  - [ ] 設定可配置的保留時間參數（預設為多久以前的資料將被刪除）
  - [ ] 提供刪除前的資料備份選項
  - [ ] 提供執行記錄和結果報告

- **技術限制**:
  - [ ] 使用 PostgreSQL 和 SQLAlchemy 進行資料庫操作
  - [ ] 必須處理可能的併發問題（與其他資料庫操作不衝突）
  - [ ] 需要與現有的後端架構和 Neon 雲端資料庫整合
  - [ ] 刪除操作必須高效且不影響資料庫整體性能

## 組件分析
- **受影響的組件**:
  - **後端資料庫模組**:
    - 變更需求: 新增刪除舊資料的腳本和相關配置
    - 依賴關係: 需要依賴 SQLAlchemy ORM 和資料庫連接設定
  
  - **排程系統**:
    - 變更需求: 需要設定定期執行的排程任務
    - 依賴關係: 可能需要使用 APScheduler 或系統 cron 作業
  
  - **日誌系統**:
    - 變更需求: 需要記錄刪除操作的結果和統計
    - 依賴關係: 需要使用現有的日誌模組

## 設計決策
- **架構**:
  - [ ] 使用獨立的 Python 腳本進行刪除操作
  - [ ] 資料庫刪除操作將使用批次處理以減少資料庫負載
  - [ ] 使用事務確保操作的原子性

- **演算法**:
  - [ ] 使用分頁查詢避免一次性讀取大量資料
  - [ ] 採用時間戳篩選方法識別需要刪除的記錄
  - [ ] 使用軟刪除策略（標記刪除而非物理刪除）或物理刪除策略的決策
