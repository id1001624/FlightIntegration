# LINE Bot 功能擴展計畫

## 需求分析
- **核心需求**:
  - [ ] 實現 FollowEvent 處理，發送歡迎訊息
  - [ ] 開發基於文字指令的航班查詢功能
  - [ ] 實現常用詞彙查詢功能
  - [ ] 設計並實現 Flex Message 航班資訊卡片
  - [ ] 確保 LINE Bot 功能穩定且回應及時

- **技術限制**:
  - [ ] 使用 LINE Messaging API SDK v3
  - [ ] 後端 Flask 框架的整合和路由設計
  - [ ] LINE 平台對訊息格式和響應時間的限制
  - [ ] 需要考慮多使用者同時查詢的效能

## 組件分析
- **受影響的組件**:
  - **LINE Controller**:
    - 變更需求: 添加新的事件處理邏輯和訊息處理功能
    - 依賴關係: 依賴 LINE SDK 和航班搜索服務

  - **Flight Search Service**:
    - 變更需求: 需要提供適合 LINE Bot 使用的搜索介面
    - 依賴關係: 依賴資料庫和航班資料模型

  - **Message Templates**:
    - 變更需求: 設計並實現各種類型的訊息模板，特別是 Flex Message
    - 依賴關係: 依賴 LINE 訊息格式規範

  - **常用詞彙服務**:
    - 變更需求: 建立常用航空旅遊詞彙的資料庫和查詢邏輯
    - 依賴關係: 可能需要建立新的資料模型

## 設計決策
- **架構**:
  - [ ] 使用模組化設計，將 LINE 訊息處理和業務邏輯分離
  - [ ] 設計可複用的訊息模板系統
  - [ ] 實現統一的錯誤處理和日誌機制

- **UI/UX**:
  - [ ] Flex Message 設計應美觀、信息豐富且易於閱讀
  - [ ] 航班查詢結果應包含關鍵信息（航空公司、航班號、出發/到達時間等）
  - [ ] 使用 LINE 特有的互動元素（如按鈕、輪播）提升用戶體驗

- **演算法**:
  - [ ] 設計航班查詢的文字解析算法，從自然語言提取查詢參數
  - [ ] 實現簡單的詞彙匹配算法用於常用詞彙查詢
