# 航班卡片詳情彈窗持續顯示修復計畫

## 需求分析
- **核心需求**:
  - [ ] 修復航班卡片詳情彈窗無法持續顯示的問題
  - [ ] 確保用戶點擊查看詳情後，彈窗能穩定顯示直到用戶主動關閉
  - [ ] 維持彈窗的互動功能（如關閉按鈕、內部選項等）
  - [ ] 確保彈窗在各種條件下（不同瀏覽器、屏幕尺寸）都能正常顯示
  - [ ] 保持彈窗樣式與現有設計一致

- **技術限制**:
  - [ ] 需與現有的 Vue 3 組件架構兼容
  - [ ] 修復應考慮現有的事件處理機制
  - [ ] 需要關注可能導致彈窗關閉的事件冒泡問題

## 組件分析
- **受影響的組件**:
  - **FlightCard 元件**:
    - 變更需求: 修改詳情按鈕的點擊事件處理
    - 依賴關係: 與 FlightDetailModal 元件的交互

  - **FlightDetailModal 元件**:
    - 變更需求: 修改彈窗的顯示/隱藏邏輯
    - 依賴關係: 可能依賴於全局狀態或父組件傳遞的狀態

  - **事件處理系統**:
    - 變更需求: 可能需要調整事件冒泡和捕獲策略
    - 依賴關係: 與 Vue 事件系統相關

## 設計決策
- **架構**:
  - [ ] 檢查現有的彈窗顯示機制（是使用 v-if、v-show 還是其他方式）
  - [ ] 確定是使用局部狀態還是全局狀態管理彈窗顯示
  - [ ] 設計合適的狀態切換邏輯確保持續顯示

- **UI/UX**:
  - [ ] 確保彈窗顯示時的背景遮罩正確設置
  - [ ] 考慮點擊彈窗外區域是否應該關閉彈窗（常見模式）
  - [ ] 確保鍵盤事件（如 ESC 鍵）的適當處理
