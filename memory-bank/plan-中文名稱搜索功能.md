# 實現中文名稱搜索功能計畫

## 需求分析
- **核心需求**:
  - [ ] 在 `AirportSelector` 元件中允許用戶使用中文名稱搜索機場
  - [ ] 搜索功能應支持模糊匹配（部分中文名稱）
  - [ ] 搜索結果應按相關性排序
  - [ ] 搜索體驗應流暢且反應迅速
  - [ ] 中文搜索結果顯示應包含機場代碼和完整中文名稱

- **技術限制**:
  - [ ] 需與現有的 `AirportSelector` 元件整合
  - [ ] 必須考慮前端性能（避免大量DOM操作或不必要的渲染）
  - [ ] 需符合現有的 UI/UX 設計風格

## 組件分析
- **受影響的組件**:
  - **AirportSelector 元件**:
    - 變更需求: 添加中文搜索功能和相關邏輯
    - 依賴關係: 依賴機場資料模型和搜索功能

  - **API 服務模組**:
    - 變更需求: 可能需要更新前端 API 服務以支持新搜索參數
    - 依賴關係: 依賴後端 API 回應格式

  - **搜索邏輯**:
    - 變更需求: 添加中文字符串匹配和排序邏輯
    - 依賴關係: 依賴機場資料結構

## 設計決策
- **UI/UX**:
  - [ ] 搜索框應顯示「搜尋機場代碼或中文名稱」的提示文字
  - [ ] 搜索結果應同時顯示機場代碼和中文名稱，便於辨識
  - [ ] 匹配的中文文本部分可以高亮顯示以增強用戶體驗

- **演算法**:
  - [ ] 使用字符串包含（contains）檢查而不是嚴格相等
  - [ ] 實現簡單的相關性排序算法（完全匹配 > 開頭匹配 > 部分匹配）
  - [ ] 考慮前端搜索性能優化策略（節流或防抖動）
